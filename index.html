🔒

API keys belong in Netlify environment variables—not in app settings, HTML, or JavaScript. A “key present” result does not guarantee billing, quota, model access, or permissions are valid.

01

Deploy the project

Upload the extracted project folder to Netlify. Keep the netlify/functions folder and netlify.toml in place so the server-side integrations deploy with the app.

02

Add environment variables

In Netlify → Site configuration → Environment variables, add GEMINI_API_KEY. Add YOUTUBE_API_KEY after enabling YouTube Data API v3 in Google Cloud. Redeploy after saving variables.

03

Test one operation

Test story generation first, then a single image, then one 8-second video. Review usage and billing before running scene batches.

04

Save a backup

Projects are stored in this browser. Export the project JSON regularly; moving to a different browser, device, or site origin does not automatically transfer local data.

IMPORTANT, BEFORE YOU GENERATE

Free app does not mean unlimited free AI

The website and local project tools can be used without a subscription. However, video-generation APIs can charge per second, and public free credits/quotas are limited and can change. Google Flow’s consumer credits are separate from this website’s API connection. This app does not bypass Flow’s limits or promise unlimited free generations.
